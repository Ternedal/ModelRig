# Kaliv / ModelRig v2.0.16 — release notes

## Changes

- Voice-stream Android client terminates when the backend emits terminal `done` or `error` (no unnecessary wait for HTTP EOF).
- Voice requests include a bounded history from the current conversation when using the **local** model, allowing follow-up references such as “blå elefant”.
- Existing cloud voice consent remains limited to the current transcript; neither Android nor the worker forwards local conversation history to a cloud LLM.
- TTS normalizes Markdown strikethrough, links, bare URLs, and residual formatting markers before synthesis.
- Adds regression tests for terminal stream events, voice-context payload, worker LLM history, cloud privacy, and spoken formatting.

## Release gate

Release from this **exact** source head only after green CI, exact-head qualification and approved release workflow. The existing release workflow must publish a complete matched asset set with signed APK, Windows worker, backend, supervisor, updater, desktop jar, SHA256SUMS and attestation. Do not replace v2.0.15 assets, retag an existing release or force-push protected main.

CI checks are not physical proof. The real device/rig end-to-end checks (especially local same-conversation memory and spoken Markdown) remain to be verified after publishing and installing the coordinated update.
